# Colour-name sources

The colour-name service maps deterministic LAB image features to human-readable
names. Source lists are kept separate so provenance remains visible.

## Meodai lists

The German list, best-of list and CSS list are consumed from the Meodai
colour-name ecosystem. `color-name-lists` declares the MIT license.

Upstream: `https://github.com/meodai/color-name-lists`

## Werner (1821)

Original work: Patrick Syme, based on Abraham Gottlob Werner, *Werner's
Nomenclature of Colours*, second edition, 1821. The original work is public
domain.

For the public repository the digital list is attributed to the Werner list
distributed by `meodai/color-name-lists` (MIT). Nicholas Rougeux's C82 project
was useful as a historical/visual reference during development, but is not
required as the licensing basis of the redistributed public data.

## Ridgway (1912)

Original work: Robert Ridgway, *Color Standards and Color Nomenclature*, 1912,
public domain. Digital extraction provenance is recorded in the JSON metadata;
the referenced npm dataset is MIT-licensed.

## Derived data

LAB values in this repository are computed from the source RGB/hex values. The
combined `bibliothek_lab.json` is generated by `build_bibliothek.py` and keeps
the source identifier on every entry.
